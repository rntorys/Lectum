Notas de las actualizaciones recientes.

16ma26me

16 mayo 2026

Calendario, respaldo de datos y registro de cambios mejorados.

  • Calendario de eventos El listado de eventos ahora se muestra como mini calendario mensual con flechas para cambiar de mes.
  • Pruebas con mas detalle Ahora puedes guardar nombre, materia, fecha, hora y temario para cada prueba o evento.
  • Proximo evento actualizado El panel superior toma en cuenta los nuevos datos del calendario, incluyendo la hora si existe.
  • JSON completo La exportacion ahora incluye materias, links, eventos y tema. La importacion mantiene compatibilidad con respaldos antiguos.
  • Reporte de actualizaciones Este panel ahora usa tarjetas y listas de cambios en vez de parrafos largos.
  • Logo personalizable Configuracion permite cambiar el logo superior por una imagen propia, como el logo de una universidad.
  • Eventos como agenda central Se retiro el apartado de pruebas pendientes para concentrar la planificacion en el calendario de eventos.

23en26mi

Primera actualizacion

Primera tanda de herramientas nuevas para convertir Lectum en un dashboard academico mas completo.

  • Accesos directos Agrega links rapidos con favicon, emoji o imagen personalizada para centralizar plataformas universitarias.
  • Colores por materia Las materias pueden tener color propio para diferenciar mejor tarjetas, detalles y elementos relacionados.
  • Seccion de actualizaciones Se agrego un espacio para explicar cambios nuevos dentro de la app.
  • Docente editable El docente de cada materia se puede modificar desde el panel de detalle.
  • Subida de archivos Cada materia puede guardar apuntes, materiales y archivos descargables.
  • Creacion de eventos Se agrego soporte inicial para registrar eventos academicos o personales.
